# Assignment 7 — HTML, CSS and Core JavaScript

All 9 questions are implemented as separate pages with separate JavaScript files. A shared `style.css` is used by all pages.

## Run the assignment
1. Extract `Assignment_7.zip`.
2. Open the `Assignment_7` folder in VS Code.
3. Open any question page (`q1.html` to `q9.html`) in a browser, or use the VS Code Live Server extension if available.
4. Each HTML file loads its matching JavaScript file.

## Files
- `q1.html` + `q1.js` — Dynamic Product List Manager / event delegation
- `q2.html` + `q2.js` — Live Character Counter
- `q3.html` + `q3.js` — Multi-Step Form
- `q4.html` + `q4.js` — Theme Switcher
- `q5.html` + `q5.js` — Image Gallery Modal
- `q6.html` + `q6.js` — Real-Time Table Filter
- `q7.html` + `q7.js` — Mouse Coordinates and Click Dots
- `q8.html` + `q8.js` — Custom Dropdown
- `q9.html` + `q9.js` — Form Validation and Submit Blocker
- `style.css` — Shared styling

No frameworks are used. Q5 uses externally hosted sample images, so an internet connection is needed to load those images.
