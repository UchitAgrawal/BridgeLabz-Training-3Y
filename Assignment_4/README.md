# Assignment 4 — JavaScript (ES6+)

This folder contains solutions for all 9 questions.

## How to run
- **Q1 and Q6:** Run in Node.js with `node q1.js` and `node q6.js`.
- **Q2–Q5 and Q7–Q9:** Open the matching HTML file in a browser. Each HTML page loads its separate JavaScript file.
- No frameworks or external libraries are used.

## Files
- `q1.js` — Product Manager (classes, objects, filter)
- `q2.html`, `q2.js` — Student Form Validator
- `q3.html`, `q3.js` — Library Management System
- `q4.html`, `q4.js` — Dynamic Form Builder
- `q5.html`, `q5.js` — Movie Ticket Booking
- `q6.js` — Employee Management System
- `q7.html`, `q7.js` — Login Form Validation
- `q8.html`, `q8.js` — Dynamic Object Updater
- `q9.html`, `q9.js` — Shopping Cart Total

All interactive pages use a shared `style.css`.
