# Assignment 5 — JavaScript (ES6+)

Solutions for all 9 questions. Each question has its own `.js` file and can be run with Node.js.

## Run
Open a terminal in this folder and run any question, for example:

```bash
node q1.js
node q2.js
```

## Files
- `q1.js` — Callback function
- `q2.js` — Callback with array operations
- `q3.js` — Arrow function `this` vs normal function
- `q4.js` — Constructor function and prototype method
- `q5.js` — Person–Student prototype inheritance
- `q6.js` — Person–Faculty–Professor prototype chain
- `q7.js` — Closure and multiplier
- `q8.js` — Custom array `myMap()` method
- `q9.js` — ES6 class inheritance compared with prototype inheritance

Only core JavaScript is used; no frameworks or external libraries are required.
