ASSIGNMENT 8 - JavaScript

Folder contents:
- Q1 to Q9: Separate JavaScript files, one for each question.
- Each file includes sample data and console output statements.

How to run:
1. Open this folder in VS Code.
2. Open the terminal in this folder.
3. Run an individual question with Node.js, for example:
   node Q1_Student_Result_Processing.js
4. Replace the filename with any Q1-Q9 file to run another question.

Notes:
- Q1 uses grade boundaries: A >= 80, B >= 60, C >= 40, otherwise F.
- Q5 fare formula: Rs. 30 base fare + Rs. 12 per kilometre.
- Q6 low-stock threshold: fewer than 5 units.
- All examples use core JavaScript (ES6+) and require no external packages.
