# Assignment 6 — Asynchronous JavaScript (ES6+)

This folder contains separate JavaScript solutions for all 10 questions.

## Requirements
- Node.js (recommended: Node 18 or newer)
- Internet connection for Q6 (Fake Store API)

## Run a question
Open a terminal in this folder and run, for example:

```bash
node q1.js
node q2.js
```

Run any file from `q1.js` through `q10.js` in the same way. Some questions intentionally include random failures, so their output can vary between runs.

## Files
- `q1.js` — Promise chaining: asynchronous coffee maker
- `q2.js` — Event loop: microtasks and macrotasks
- `q3.js` — Callback-to-Promise bug tracker
- `q4.js` — Concurrent servers with Promise.all() and Promise.race()
- `q5.js` — Callback hell and async/await pipeline
- `q6.js` — Fetch products from Fake Store API
- `q6.html` — Optional browser page for dynamic product cards
- `q7.js` — Promise.allSettled() dashboard modules
- `q8.js` — Order retry mechanism
- `q9.js` — Event loop execution order
- `q10.js` — Async food delivery pipeline

All JavaScript solutions use core JavaScript and no frameworks.
